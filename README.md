# JointLedger

A smart joint-account expense management PWA built with HTML, CSS, JavaScript, Tailwind CSS, Chart.js, and IndexedDB.

## Features
- 💰 Track individual contributions and expenses
- 🤝 Shared expense splitting (equal split)
- 📊 Spending analytics with Chart.js
- 🔄 Settlement engine — "Who owes who"
- 🌐 Bilingual support (English / Tamil)
- 🌗 Theme switching (Light / Dark / Auto)
- 📱 Installable PWA — works offline
- 💾 Export/Import data backup (JSON + CSV)
- 👴 Elderly-friendly, large touch targets

## How to Run
```bash
npx serve .
```
Then open `http://localhost:3000` in your browser.

## Tech Stack
- HTML5, CSS3, JavaScript (ES6+)
- Tailwind CSS (CDN)
- Chart.js
- IndexedDB
- Service Workers
